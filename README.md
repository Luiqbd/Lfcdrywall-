Site profissional para serviços de instalação de Drywall.

## Sobre o Projeto

Este é o site institucional da LFC Drywall, especializado em serviços de instalação de drywall para residências e empresas.

## Configuração do GitHub Pages

Para hospedar este site no GitHub Pages:

1. Crie um repositório no GitHub chamado `lfcdrywall`
2. Faça upload do arquivo `index.html`
3. Vá em Settings > Pages
4. Em "Source", selecione "Deploy from a branch"
5. Selecione a branch "main" e a pasta "/ (root)"
6. Clique em Save

Após alguns minutos, seu site estará disponível em: `https://seu-usuario.github.io/lfcdrywall`
